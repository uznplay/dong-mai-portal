Tạo Password Hash

Tạo mã băm bcrypt cho password

Hướng dẫn

  1. Nhập password vào ô trên
  2. Nhấn "Tạo Hash"
  3. Copy kết quả và chạy SQL trong Supabase
  4. Đăng nhập với password ban đầu

Lưu ý

Password mặc định: admin123
Hash: $2a$10$N9qo8uLOickgx2ZMRZoMyeIjZRGdjGj/nMskyBPMa6KCdXjQGpQla

Đã tạo sẵn hash cho "admin123"

Có thể sử dụng ngay nếu không cần thay đổi
